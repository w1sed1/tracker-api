# Трекер звичок

Вебсервіс для щоденного відстеження звичок зі статистикою.

## Можливості

- додавання, перейменування, зміна кольору і видалення звичок;
- відмітка виконання за будь-який з останніх 7 днів одним кліком (майбутні дні відмітити не можна);
- статистика по кожній звичці: поточна і рекордна серія, кількість відміток, відсоток виконання за 30 днів і за весь час, графік по тижнях (12 тижнів), календар за 26 тижнів;
- загальна статистика: скільки виконано сьогодні, виконання за 30 днів, графік по днях, найкращі і найслабші дні тижня;
- REST API з документацією Swagger.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m app.seed                 # необов'язково: демо-звички з історією за 90 днів
uvicorn app.main:app --reload
```

- Застосунок: http://127.0.0.1:8000
- Swagger UI: http://127.0.0.1:8000/docs

Дані зберігаються у файлі `habits.db` в корені проєкту. Інший файл можна задати змінною `HABITS_DB=/шлях/до/файлу.db`.

## API

| Метод  | Шлях                                     | Опис                                                  |
| ------ | ---------------------------------------- | ----------------------------------------------------- |
| GET    | `/api/habits`                            | список звичок з короткою статистикою                  |
| POST   | `/api/habits`                            | створити звичку `{"name": "...", "color": "#4f7cff"}` |
| PUT    | `/api/habits/{id}`                       | змінити назву і колір                                 |
| DELETE | `/api/habits/{id}`                       | видалити звичку з усією історією                      |
| GET    | `/api/habits/{id}/stats`                 | детальна статистика звички                            |
| PUT    | `/api/habits/{id}/checkins/{YYYY-MM-DD}` | відмітити день                                        |
| DELETE | `/api/habits/{id}/checkins/{YYYY-MM-DD}` | зняти відмітку                                        |
| GET    | `/api/overview`                          | загальна статистика                                   |

## Як рахується статистика

- **Поточна серія:** скільки днів поспіль звичку виконано до сьогодні включно. Невідмічений сьогоднішній день серію ще не перериває.
- **Відсоток виконання:** відмічені дні поділені на всі дні від початку відстеження. Відстеження починається з дня створення звички або з найранішої відмітки, якщо вона раніша.
- **Загальна статистика** враховує звичку лише з дня, коли почалося її відстеження.

## Структура

```
app/
  main.py      маршрути API і роздача сторінки
  db.py        робота з SQLite
  stats.py     розрахунок статистики (чисті функції)
  seed.py      демо-дані
  static/      index.html, app.js, style.css
tests/         pytest: статистика і API
```
